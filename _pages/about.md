## Hi, I'm Dhruvil 👋

I'm a **Software Development Engineer (SDE 3)** at [Pirimid Fintech](https://pirimidtech.com), specializing in **Backend Engineering, Distributed Systems, and FinTech**. I design and build high-performance backend systems for financial platforms, with experience working on systems serving **10M+ users** across various projects and backend systems handling **50M+ API calls per month**.

My work focuses on building systems that are **scalable, reliable, efficient, and built to handle high volumes of data and traffic**.

---

## What I Do

- 🔧 **Backend Engineering** - Designing and building APIs, microservices, data pipelines, and backend platforms
- ⚡ **Distributed Systems** - Building high-throughput, low-latency systems that work reliably at scale
- 🏗️ **System Design** - Designing system architecture and making technical decisions for complex backend problems
- 📈 **Performance & Scalability** - Finding bottlenecks and improving system performance, throughput, and resource usage
- 💰 **FinTech** - Building financial data platforms - Trading, Payment Processing, Portfolio Management Systems
- ☁️ **Cloud & Infrastructure** - Building and running production systems on AWS, Kubernetes, and Docker
